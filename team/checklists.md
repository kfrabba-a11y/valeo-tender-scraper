# "Done" checklists by stage

Work is done only when every box for its stage is ticked. If a box can't be ticked, the work isn't done: report it as **Blocked**.

## 1. Found (scout)
- [ ] Task on the board: title, reference, issuer, closing date and time (Lebanon, 12-hour clock), docs folder.
- [ ] All the published documents are downloaded, or the missing ones are named.
- [ ] Not a duplicate.

## 2. Reviewed (reviewer)
- [ ] review.md is complete: compliance matrix, document checklist, dates, risks, clarifications, recommendation.
- [ ] Eligibility killers are checked first.
- [ ] The bid/no-bid need is on the board.

## 3. Decided (owner)
- [ ] The owner answered the need ("Approve" or "Decline", with a note).
- [ ] The CEO moved the task to `working`, or closed it.

## 4. Priced (estimator)
- [ ] Every line is priced with a build-up; formulas are live; totals checked.
- [ ] The assumptions sheet is done; the client's format is unchanged.
- [ ] The price decision need is on the board.

## 5. Proposal written (proposals)
- [ ] Every evaluation criterion is covered; facts come from company-facts.md only.
- [ ] Format, language and page limits are met.

## 6. Ready to submit (submissions)
- [ ] Every required document is present and named as the tender asks.
- [ ] Email drafts are in the owner's mailbox (not sent).
- [ ] The "ready to submit" need is on the board 24+ hours before closing.

## 7. Submitted (owner)
- [ ] The owner confirms it was submitted. The task moves to `done`, with the submission time in its note.
